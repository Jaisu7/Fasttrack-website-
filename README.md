# Fastrack Metallic Website

React/Vite application with a scroll-controlled manufacturing journey, interactive process demonstrations and a Three.js product showroom.

Requires Node.js 22.12 or newer.

```powershell
npm ci
npm test
npm run dev
```

Run `npm run build` to create the production build.

This repository snapshot includes application code, runtime images/fonts, tests and build configuration. Private chat archives, internal documentation and hosting metadata are excluded.

Product models are illustrative concepts. The enquiry interface prepares a draft and does not send messages automatically.
